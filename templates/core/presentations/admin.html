RedacLo est une plateforme d'édition collaborative. En tant qu'administrateur, vous disposez de tous les droits sur l'ensemble du système.

Vous gérez les comptes utilisateurs : vous invitez de nouveaux membres, vous leur attribuez un rôle, et vous pouvez modifier ou suspendre un compte si nécessaire. Vous avez également accès à l'interface d'administration Django, qui vous permet d'inspecter les articles, les versions, les annotations et les notifications, et d'intervenir directement sur les données si besoin.

Vous cumulez les pouvoirs de tous les autres rôles : vous pouvez créer un article en tant qu'auteur, proposer une relecture, éditer et valider un texte. Cette position est prévue pour la maintenance et les cas particuliers, pas pour le travail éditorial courant.

Votre rôle est de faire fonctionner la plateforme, pas de produire du contenu. Les invitations que vous envoyez sont à usage unique et limitées dans le temps. Vous êtes également responsable de la configuration technique : variables d'environnement, sauvegardes, migrations.
